# Deployment files

Production SG-Gateway 021 uses native Ubuntu services and systemd.

- `../install.sh` — current full installer source.
- `full-uninstall-ubuntu.sh` — destructive full uninstall with confirmation.
- `install-wgcf-cli.sh` — verified WARP helper installation.
- `systemd/` and `*.service` — service templates used by the installer.

Old Docker deployment is not part of this repository line.
