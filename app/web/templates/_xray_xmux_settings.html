После сохранения будет установлен стандартный клиентский XMUX-пресет:

maxConnections2-4
cMaxReuseTimes300-600
hMaxRequestTimes1000-2000
hMaxReusableSecs1200-2400

Остальные поля Client Extra сохраняются; объект xmux заменяется этим пресетом.

После сохранения будет установлен уменьшенный клиентский XMUX-пресет:

maxConcurrency0
maxConnections6
cMaxReuseTimes0
hMaxRequestTimes600-900
hMaxReusableSecs1800-3000
hKeepAlivePeriod0
Остальные поля Client Extra сохраняются; объект xmux заменяется этим пресетом.

В ручном режиме после сохранения используется весь Client Extra JSON как есть. Объект xmux обязателен.
