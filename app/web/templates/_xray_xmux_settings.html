ПАРАМЕТРЫ XMUX

XMUX

Фиксированный актуальный пресет Xray-core 26.7.28:

maxConcurrency0
maxConnections3
cMaxReuseTimes0
hMaxRequestTimes600-900
hMaxReusableSecs1800-3000
hKeepAlivePeriod0
Поля не редактируются. Остальные поля Client Extra сохраняются.

Фиксированный профиль для РФ с более быстрой ротацией:

maxConcurrency5
maxConnections0
cMaxReuseTimes0
hMaxRequestTimes300-600
hMaxReusableSecs900-1800
hKeepAlivePeriod0
Поля не редактируются. Остальные поля Client Extra сохраняются.

Ручной XMUX. Можно задавать целое число или диапазон A-B; hKeepAlivePeriod — только целое.

{}
Положительные maxConnections и maxConcurrency одновременно запрещены. Client Extra JSON остаётся источником дополнительных полей.
Выбор режима ещё ничего не применяет. Параметры сохранятся только по кнопке «Сохранить XMUX».
