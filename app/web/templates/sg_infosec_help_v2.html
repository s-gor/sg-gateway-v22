СВЕДЕНИЯ ОБ IP

Кому принадлежит адрес

Рядом с внешним IP SG InfoSec показывает страну, автономную систему, название оператора сети и маршрутизируемый префикс.

144.225.6.182 🇺🇸 США · AS7488 · CNServer LLC Сеть 144.225.6.0/23 · тип сети из локальной репутации

Это сведения о сети, а не установление личности. По публичному IP нельзя надёжно определить конкретного человека или владельца устройства. Название означает организацию, автономная система которой объявляет адресный диапазон в интернете.

Источники и приватность

  • страна определяется по локальной GeoIP-базе SG-Gateway;
  • ASN, оператор и сетевой префикс запрашиваются у RIPEstat;
  • во внешний сервис передаётся только проверяемый публичный IP;
  • пароли, cookies, токены, URL, тела запросов и данные клиентов не передаются.

Влияние на защиту

Сведения RIPEstat используются только для понятного объяснения события. Они сами по себе не создают блокировку и не повышают риск. Решение принимают правила SG InfoSec, Web Shield, явно загруженная локальная репутация, allowlist и ручные действия администратора.

Кэш и недоступность сервиса

Успешные ответы сохраняются локально на семь дней. Неудачный запрос повторяется после короткого отрицательного кэша. Если RIPEstat недоступен, Security продолжает открываться, а вся защита работает без изменений; вместо ASN показывается, что сведения о сети недоступны.

Отключить внешнее справочное обращение можно переменной SG_INFOSEC_IP_INTEL_ENABLED=0. Локальная страна и локальная репутация при этом сохраняются.
