# Maintenance и диагностика

## Резервные копии

Перед рискованными изменениями SG-Gateway создаёт страховочную копию управляемых файлов и runtime-state. Пользовательские копии доступны в разделе Maintenance.

## Диагностика

Диагностика собирает:

- состояние systemd-служб;
- состояние backend;
- сведения о Xray, AmneziaWG, Mihomo и sing-box;
- основные журналы;
- конфигурационные проверки;
- ошибки последней операции.

Секреты должны быть удалены из diagnostic bundle.

## Обновление

Обновление из GitHub использует тот же bootstrap, что и установка. Updater создаёт копию и выполняет rollback, если новая версия не проходит проверку.

## Проверка после изменений

- `System` открывается без Internal Server Error;
- `/health` отвечает;
- Nginx проходит `nginx -t`;
- Xray проходит `xray run -test`;
- нужные listener активны;
- клиентская subscription строится;
- GitHub Actions зелёный.
